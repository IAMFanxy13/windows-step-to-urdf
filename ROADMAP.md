# Roadmap

## Next

- Validate more independently licensed robot assemblies and publish anonymized benchmark metrics.
- Improve exact interface/contact classification and large-assembly performance.
- Complete axis/origin picking for every supported analytic B-Rep feature.
- Add a signed, dependency-free Windows package with a reviewed OCCT compliance bundle and SBOM.
- Expand export compatibility testing in common URDF consumers.

## Intentionally out of scope

Closed loops, parallel mechanisms, gears, linkages, mimic joints, multi-actuator joints, dynamics, inverse kinematics, and real hardware control.
