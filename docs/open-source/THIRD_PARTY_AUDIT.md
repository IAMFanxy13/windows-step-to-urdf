# Third-party audit

Runtime dependencies are installed from npm and PyPI lock/requirements files; no third-party repository source tree is vendored. The upstream `urdf-loaders` Apache-2.0 license is retained under `licenses/` for provenance. Direct dependencies and their roles are documented in `THIRD_PARTY_NOTICES.md`.

The public AP242 example uses one pinned MIT-licensed SG51R body definition from `adafruit/Adafruit_CAD_Parts` commit `ab3dfc47c32468ba87e7652556cab25efd906eb0`. Its exact license, source path, raw URL, and SHA-256 are preserved under `third_party/adafruit_sg51r/`. Two occurrences are composed with original deterministic horn, bracket, link, and base geometry generated by this repository. No private CAD, external font, or icon pack is included.

Binary Windows redistribution is not yet offered. A future bundled OCP/OCCT runtime must include the applicable LGPL-2.1 text, Open CASCADE exception, notices, and relinking/source rights required by that license.
